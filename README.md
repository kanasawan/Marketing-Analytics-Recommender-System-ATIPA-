# Atipa Shop Recommender System

**โครงงานวิชา DSI211 Marketing Analytics**  
**ระยะเวลา:** สิงหาคม 2568 - พฤศจิกายน 2568

## เกี่ยวกับโปรเจกต์

โปรเจกต์นี้จัดทำระบบแนะนำสินค้าสำหรับ Atipa Shop เพื่อช่วยเพิ่มยอดขายและแนะนำสินค้าให้เหมาะกับลูกค้าแต่ละกลุ่ม โดยนำข้อมูลพฤติกรรมลูกค้ามาวิเคราะห์ร่วมกับข้อมูลสินค้าจาก Shopee

## ข้อมูลที่ใช้

- ข้อมูลแบบสอบถามจากลูกค้า 349 คน
- ข้อมูลสินค้า Shopee 664 รายการจาก Web Scraping
- ข้อมูลเกี่ยวกับอายุ รายได้ พฤติกรรมการซื้อ โปรโมชั่น ราคา ส่วนลด คะแนน รีวิว และยอดขาย

## ขั้นตอนการทำงาน

1. เก็บข้อมูลลูกค้าผ่าน Google Forms และรวบรวมข้อมูลสินค้าจาก Shopee ด้วย Python
2. ทำความสะอาดข้อมูล ลบข้อมูลว่างและข้อมูลซ้ำ
3. แปลงข้อมูลให้อยู่ในรูปตัวเลขด้วย One-Hot Encoding และ Mapping
4. ปรับค่าตัวแปรให้อยู่ในช่วง 0-1 ด้วย Min-Max Normalization
5. วิเคราะห์ข้อมูลเบื้องต้นด้วย Exploratory Data Analysis (EDA)
6. แบ่งลูกค้าด้วย K-Means Clustering โดยใช้ Elbow Method เลือกจำนวนกลุ่มที่เหมาะสม
7. กำหนดน้ำหนักของสินค้าให้เหมาะกับพฤติกรรมลูกค้าแต่ละกลุ่ม
8. วางแผนประเมินผลด้วย A/B Testing

## กลุ่มลูกค้าที่พบ

- **กลุ่มรายได้สูงและวางแผนก่อนซื้อ:** สนใจส่วนลดสูงและคลิกดูโปรโมชั่นบ่อย
- **กลุ่มซื้อทันทีเมื่อพบโปรโมชั่น:** ตอบสนองต่อโปรโมชั่นสูง เหมาะกับสินค้าที่รีวิวดีและขายดี
- **กลุ่มประหยัดและเปรียบเทียบก่อนซื้อ:** สนใจโปรโมชั่น แต่ต้องการความน่าเชื่อถือก่อนตัดสินใจ

## ระบบแนะนำสินค้า

ระบบจะคำนวณคะแนนสินค้าจากส่วนลด ความเหมาะสมกับลูกค้า คะแนนรีวิว จำนวนรีวิว และยอดขาย โดยกำหนดน้ำหนักต่างกันตามลูกค้าแต่ละกลุ่ม เพื่อให้คำแนะนำตรงกับพฤติกรรมมากขึ้น
